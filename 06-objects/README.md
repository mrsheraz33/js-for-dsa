# JavaScript Objects

This project contains practice examples of JavaScript objects and the basic object operations that are important for JavaScript fundamentals and Data Structures & Algorithms (DSA).

## Topics

- Creating Objects
- Accessing Object Properties
- Dot Notation
- Bracket Notation
- Updating Object Properties
- Adding New Properties
- Deleting Properties
- Looping Through Objects (`for...in`)

## Purpose

This code is written for JavaScript practice and to strengthen the concepts used in DSA.
