# JavaScript Map & Set

This project contains practice examples of JavaScript `Map` and `Set`, which are useful data structures for modern JavaScript and Data Structures & Algorithms (DSA).

## Topics

- Creating a `Map`
- `set()`
- `get()`
- `has()`
- `size`
- Creating a `Set`
- Removing Duplicate Values
- `add()`
- `delete()`
- Converting a `Set` to an Array using the Spread Operator

## Purpose

This code is written for JavaScript practice and to strengthen the concepts used in DSA.
