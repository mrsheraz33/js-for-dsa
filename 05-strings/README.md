# JavaScript Strings

This project contains practice examples of JavaScript strings and the most commonly used string methods that are important for JavaScript fundamentals and Data Structures & Algorithms (DSA).

## Topics

- `length`
- `slice()`
- `substring()`
- `split()`
- `join()`
- `replace()`
- `replaceAll()`
- `trim()`

## Purpose

This code is written for JavaScript practice and to strengthen the concepts used in DSA.
