# JavaScript Arrays

This project contains practice examples of JavaScript arrays and the most commonly used array methods that are important for JavaScript fundamentals and Data Structures & Algorithms (DSA).

## Topics

- Accessing Array Elements
- `push()` and `pop()`
- `shift()` and `unshift()`
- `slice()` vs `splice()`
- `sort()` and `reverse()`
- `includes()`
- `indexOf()`

## Purpose

This code is written for JavaScript practice and to strengthen the concepts used in DSA.
