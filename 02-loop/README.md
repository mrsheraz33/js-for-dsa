## Topics Covered

- `for` Loop
- `while` Loop
- `for...of` Loop

## What I Learned

- Use the `for` loop when the number of iterations is known.
- Use the `while` loop when repetition depends on a condition.
- Reverse an array using the `while` loop.
- Use the `for...of` loop to iterate through array values.
- Calculate the sum of array elements using a loop.
