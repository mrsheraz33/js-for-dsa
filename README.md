# JavaScript for DSA

This repository contains the essential JavaScript topics that should be understood before starting Data Structures and Algorithms (DSA).

The purpose of this repository is to strengthen JavaScript fundamentals through simple examples and practice code.

## Topics

### Basics
- Variables (`let`, `const`)
- Data Types
- Operators
- if...else
- switch

### Loops
- for
- while
- for...of

### Functions
- Function Declaration
- Arrow Functions
- Parameters
- Return

### Arrays
- Access Elements
- push()
- pop()
- shift()
- unshift()
- slice()
- splice()
- sort()
- reverse()
- includes()
- indexOf()

### Strings
- length
- slice()
- substring()
- split()
- join()
- replace()
- trim()

### Objects
- Create Objects
- Access Properties
- Update Properties
- Delete Properties
- Loop Through Properties

### ES6 Features
- Destructuring
- Spread Operator (`...`)
- Rest Operator (`...`)
- Template Literals

### Map & Set
- Map
- Set

### Recursion
- Basic Recursion
- Recursive Thinking

### Time Complexity
- O(1)
- O(n)
- O(log n)
- O(n²)

## Goal

- Build a strong JavaScript foundation.
- Prepare for Data Structures and Algorithms.
- Practice concepts with clean and simple code.
- Learn step by step before solving DSA problems.
